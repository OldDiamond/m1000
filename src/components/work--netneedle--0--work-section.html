NetNeedle maps external attack surfaces, reviews web security findings, and turns scan evidence into actionable reports.

About the Project

Configure network, web, or advanced web assessments from one workspace.

Track scan progress, review evidence, and return to persisted results.

From Assessment to Action

Scope targets, run controlled checks, and review findings by severity and confirmation status.

Evidence-led Reporting

Export executive and technical reports as HTML or PDF, with risk summaries and remediation guidance.

AI-assisted narratives use validated evidence and deterministic fallbacks.

Built for Background Work

FastAPI serves the application while Celery and Redis manage long-running jobs.

PostgreSQL stores assessment state; scans and reports run in separate workers.

Security Tooling

Integrates Nmap, Masscan, Nuclei, WhatWeb, Nikto, and testssl.sh.

Technology Stack

Python, FastAPI, PostgreSQL, Celery, Redis, React, Vite, Three.js, Ollama, Docker, and Nginx.
