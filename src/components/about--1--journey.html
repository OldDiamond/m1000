My Journey

My path combines computer science studies at IISAT with hands-on systems work. Programming, networking, and software development have helped me understand how applications and infrastructure fit together, and where security weaknesses can appear.

Working on infrastructure at 11ven Tech Yards gave me practical experience with Linux servers, troubleshooting, and system hardening. Writing Python and PowerShell tools helped me turn repeated diagnostic tasks into reliable automation.

That experience carried into NetNeedle. I built a cloud-based vulnerability scanner with Python and FastAPI, bringing together web application checks, REST API testing, and reporting. The goal is to turn findings into remediation guidance that developers can use.

Today, I keep developing my web security skills through practical testing, Hack The Box, and CTF challenges. I'm interested in work that connects careful vulnerability analysis with building better security tools.
